# INSERTION BLOCK / การแทรกและวางบล็อก

Category 08 in the main AutoLISP Collection.

Place each command showcase in a separate subfolder with its own `index.html` and local assets. Current pages:

- `Xline_Intersection_Insert/index.html` for `xline_intersect_block_xl2_`, with the supplied MP4 demonstration.
- `Polyline_Vertex_Block_Placement/index.html` for `insert_by_polyline_blk2pline`, with the supplied GIF. Moves existing blocks to polyline vertices; does not create new block references.
- `Boundary_Center_Block_Placement/index.html` for `insert_by_intersect_blk2in_`, with the supplied GIF. Moves existing blocks to guide intersections used as a boundary-center reference; does not directly calculate an area centroid or create new blocks.

CAD source originals remain untouched; these showcases do not certify CAD compatibility or full test coverage.

The main collection folder is the source of truth. Updating the portfolio scans category folders and their immediate command-page subfolders, then rebuilds the encrypted directory using the existing password.
