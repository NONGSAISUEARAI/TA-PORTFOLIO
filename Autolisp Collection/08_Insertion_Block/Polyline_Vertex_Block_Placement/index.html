TWO PLACEMENT MODES

เลือกวิธีจัดวางให้เหมาะกับงาน

01 / INDIVIDUAL

เลือกทีละบล็อก

มีเครื่องหมายแสดงจุด Vertex ปัจจุบัน แล้วให้เลือกบล็อกเดิมเพื่อย้ายไปยังจุดนั้น เหมาะเมื่ออยากกำหนดว่าบล็อกใดจะอยู่ที่จุดใด

02 / SELECTION SET

ใช้ชุดบล็อกที่เลือก

นำบล็อกจากชุดที่เลือกมาเรียงคู่กับ Vertex ตามลำดับของชุดเลือก ไม่ได้จัดเรียงบล็อกตามระยะใกล้–ไกลให้อัตโนมัติ

ภาพสาธิตแสดงการใช้งานที่บันทึกไว้ ไม่ใช่การรับรองผลทดสอบทุกกรณีหรือทุกเวอร์ชัน CAD
