01 / CROSSING GUIDES

กำหนดจุดกลางด้วยเส้นอ้างอิง

เตรียมเส้นให้ตัดกันที่ตำแหน่งกลางพื้นที่ที่ต้องการก่อนรันคำสั่ง ตัวคำสั่งใช้จุดตัดของเส้นที่เลือก ไม่ได้สร้างเส้นอ้างอิงหรืออ่านจุดศูนย์กลางจาก Boundary ให้อัตโนมัติ

02 / EXISTING BLOCK PLACEMENT

เลือกบล็อกให้แต่ละจุด

แสดงเครื่องหมายของจุดอ้างอิง แล้วให้เลือกบล็อกเดิมเพื่อย้ายไปยังจุดนั้น หากมีหลายจุด จะจัดลำดับจุดตามพิกัด X ไม่ได้จัดเรียงเป็นแถวหรือคอลัมน์ให้โดยเฉพาะ
