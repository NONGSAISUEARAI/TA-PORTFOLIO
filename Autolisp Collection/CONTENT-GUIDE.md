# Portfolio presentation policy

The user supplies AutoLISP code only so the assistant can understand the behavior and write accurate Thai/English descriptions. Do not modify or execute original CAD code, include source listings, or create downloadable LSP files unless explicitly requested later.

Public command pages should show the command name, user-facing purpose, simple workflow and supplied GIF/video. Do not display implementation helper names/counts, dependency maps or internal source-review/debugging sections. Keep necessary functional limitations in plain language, without suggesting unverified compatibility or complete testing.

Retain the approved starfield palette, media controls, language switching and navigation. Developer analysis in local documentation/backups is not public page content; do not publish those internal notes when preparing a deployment.
