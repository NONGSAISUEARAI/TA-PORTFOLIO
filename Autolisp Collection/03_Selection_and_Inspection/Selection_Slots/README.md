# Selection Slots — video showcase

หน้า TH/EN สำหรับ Save / Load / Add / Remove คงพื้นหลังดาวเดิม เปลี่ยน GIF เป็น HTML video พร้อมปุ่มควบคุม กดเล่นเอง ไม่ autoplay หรือเล่นวน ไม่มี password protection ของตนเอง เก็บนอก publish/ ยังไม่ได้เชื่อมกับพอร์ตที่เข้ารหัส และไม่เผยแพร่ GitHub ในรอบนี้

## ใช้งาน

เปิด index.html ผ่านเบราว์เซอร์ หรือ localhost ไฟล์ assets/videos/selection-saveloadadddelete.mp4 เป็นสำเนาคลิปที่ผู้ใช้ส่งมา ไม่แก้หรือตัดต่อไฟล์ต้นฉบับ คลิปเดียวใช้ร่วมทั้ง 4 แท็บ แท็บเปลี่ยนรายละเอียดคำสั่ง ไม่ใช่ chapter และไม่เดาเวลาเริ่มของแต่ละคำสั่ง

ปุ่มขยายเปิดกรอบใหญ่ที่ตำแหน่งเวลาเดิมและหยุดรอให้กดเล่นเอง ปิดกรอบแล้วหยุดเล่น ไม่มีเสียงสองชุดพร้อมกัน สลับแท็บคำสั่งหรือซ่อนหน้าเบราว์เซอร์จะหยุดวิดีโอ ปุ่มทดลองวิดีโออื่นรับ MP4/WebM ไม่เกิน 256 MB ตรวจ header เบื้องต้น ใช้ Blob URL ในเครื่อง ไม่ส่งไฟล์ ไม่บันทึก Refresh หรือปุ่มใช้คลิปเดิมกลับไปคลิปที่แนบไว้ การตรวจ header ไม่รับรอง codec หรือความปลอดภัยทั้งหมด

## ก่อนนำขึ้นเว็บ

1. วิดีโอใช้ object-fit: contain ไม่ตัดภาพ อัตราส่วนต่างจากกรอบจะมีพื้นที่ว่างรอบคลิป
2. ตรวจข้อมูลลูกค้า ชื่อโครงการ และข้อมูลส่วนตัวในคลิปก่อนเผยแพร่
3. MP4 ที่เป็น URL สาธารณะเปิดได้โดยตรง แม้หน้าเว็บมีรหัสผ่าน ต้องออกแบบการปกป้องสื่อเพิ่มก่อนขึ้นเว็บหากต้องการล็อกคลิป

## ขอบเขตเนื้อหา

ชื่อสั้นบนแท็บเป็นป้าย workflow ไม่ใช่ command aliases ใช้ชื่อจริงจาก source ในกรอบ Command Overview คลิปที่แนบไม่ใช่การรับรองผลทดสอบ CAD ทุกกรณี ไม่ใส่ไฟล์ LSP หรือคำกล่าวอ้างด้านประสิทธิภาพ ไม่แก้ไขหรือรัน AutoLISP ต้นฉบับ

รายละเอียดอิงจากโค้ด 4 คำสั่งที่ผู้ใช้แนบ และ helper TA:combine_selection_set_ ในไฟล์หลัก Save/Load/Add/Remove ใช้ตัวแปร ssA–ssJ ร่วมกัน; Load เรียก helper ส่วนคำสั่งอื่นไม่พบ custom helper ภายนอก ชุดเลือกเก็บในหน่วยความจำ ไม่ใช่การบันทึก selection ลงไฟล์ ยังต้องแก้สถานะ ssG/Slot 10 ของ Save/Load และตรวจการเลือกว่างก่อนจัดเป็นรุ่นพร้อมใช้

ใช้แนวทาง Sites คงรูปแบบเดิม แสดงหลักฐานวิดีโอโดยไม่อ้างผลทดสอบเกินจริง และตรวจหน้าเว็บในเครื่อง ไม่มี CDN, telemetry, API ส่งไฟล์ หรือ browser storage ปุ่มหยุดดาวควบคุมเฉพาะพื้นหลัง ส่วนวิดีโอใช้ Play/Pause ของตนเอง
