ปรับ Layer และสีของบล็อกในขั้นตอนเดียว

ตั้งวัตถุที่เลือกเป็น ByLayer และย้ายไปยัง Layer ปลายทาง สำหรับบล็อก จะปรับส่วนประกอบที่รองรับในนิยามบล็อก รวมถึงนิยามบล็อกซ้อนที่พบ ไม่ได้เลือกค่าสีแยกจาก Layer

ลำดับการใช้งาน3 STEPS
  1. เรียกคำสั่งแล้วเลือก Layer จากรายการ หรือเลือก USER INPUT LAYER เพื่ออ้างอิงจากวัตถุในแบบ
  2. ใช้วัตถุที่เลือกไว้ล่วงหน้า หรือเลือกวัตถุและบล็อกที่ต้องการปรับ
  3. กด Enter ที่ข้อความยืนยัน แล้วตรวจ Layer และสีของผลลัพธ์ในแบบ
02 / TWO LAYER SOURCES

เลือกรายการ หรืออ้างอิงจากวัตถุ

ใช้ Layer ที่เตรียมไว้ในรายการ หรือเลือกวัตถุเพื่ออ่านชื่อ Layer ที่ต้องการ สีสุดท้ายอิงสีของ Layer ปลายทาง จึงควรตรวจ Layer นั้นในแบบก่อนใช้

03 / SHARED BLOCK DEFINITION

ตรวจบล็อกที่ใช้นิยามร่วมกัน

คำสั่งแก้ส่วนประกอบในนิยามบล็อก จึงอาจเปลี่ยนบล็อกตัวอื่นที่ใช้นิยามเดียวกัน รวมถึงบล็อกซ้อน ไม่ใช่การย้อมเฉพาะตัวที่เลือก ควรทดลองกับสำเนาแบบก่อนใช้งานจริง

รองรับส่วนประกอบบางชนิดและมีข้อยกเว้นสำหรับเส้นที่กำหนดไว้ ภาพสาธิตเป็นการใช้งานที่บันทึก ไม่ใช่การรับรองทุกชนิดบล็อกหรือทุกเวอร์ชัน CAD
