# TA-PORTFOLIO

หน้า Password-only + Starfield Warp สำหรับเปิดพอร์ตด้วยการถอดรหัสในเบราว์เซอร์ ไม่ส่งรหัสผ่านให้เซิร์ฟเวอร์ ไม่ใช้ชื่อผู้ใช้ ไม่เก็บ password/key ใน cookie, localStorage หรือ sessionStorage

## ไฟล์สำหรับขึ้นเว็บ

ชุดล็อกอินอยู่ใน `publish/` อย่าอัปโหลดทั้งโฟลเดอร์ TA-PORTFOLIO หากจะเผยแพร่ลิงก์หน้าคำสั่งด้วย ต้องจัดชุดหน้ารายละเอียดและ assets จาก `Autolisp Collection/` เพิ่มตามโครงสร้างลิงก์ โดยเข้าใจว่าหน้ารายละเอียดเหล่านั้นไม่ได้เข้ารหัส รอบนี้อัปเดตในเครื่องเท่านั้น ยังไม่ได้จัดชุดหรืออัปโหลดเว็บออนไลน์

```text
TA-PORTFOLIO/
  publish/
    index.html                 หน้า Password + พื้นหลัง Starfield
    css/login.css
    js/login.js                ถอดรหัสในเบราว์เซอร์และแสดงพอร์ต
    js/encrypted-portfolio.js   เนื้อหาพอร์ตที่เข้ารหัสแล้ว
  private/                     ห้ามเผยแพร่ / กำหนด ignore ไว้ใน .gitignore
    access-key.json             รหัสเริ่มต้นสำหรับเจ้าของ
    build-checks.json
  source/                      พอร์ตต้นฉบับสำหรับแก้ไข / ห้ามเผยแพร่ชุดนี้
    index.html
    css/home.css
    js/home.js
  tools/
    build-encrypted-portfolio.mjs
  previews/                    ภาพตรวจหน้าเว็บ / ไม่รวมในชุดอัปโหลด
```

เปิด `private/access-key.json` ในเครื่องเพื่อดูรหัสปัจจุบัน รหัสไม่ถูกฝังไว้ใน JavaScript สาธารณะ ผู้ใช้เปลี่ยนเป็นรหัสสั้นผ่านการตั้งค่าเฉพาะในไฟล์ส่วนตัวแล้ว จึงไม่อ้างว่ารหัสปัจจุบันสุ่มหรือแข็งแรง ควรใช้วลียาวก่อนเผยแพร่ และแบ่งปันรหัสกับผู้ชมที่ต้องการโดยช่องทางที่ไว้ใจได้เท่านั้น

รหัสถูกใช้สร้าง key ด้วย PBKDF2-SHA256 (600,000 iterations, salt สุ่ม 16 bytes) แล้วถอดเนื้อหาด้วย AES-256-GCM (IV สุ่ม 12 bytes, 128-bit authentication tag) ตัวเว็บโหลด ciphertext แต่ไม่แสดงหรือรันเนื้อหาพอร์ตจนกว่าจะถอดรหัสสำเร็จ จากนั้นแสดง HTML/CSS/JS แบบ self-contained ใน sandboxed iframe ผ่าน srcdoc ไม่มีการส่งรหัสผ่านหรือ HTML ที่ถอดรหัสกลับไปเซิร์ฟเวอร์ แต่ไฟล์เว็บสาธารณะยังต้องโหลดตามปกติ

อัปเดต 2026-10-12: หลังเปิดพอร์ตสำเร็จ จำ **HTML ที่ถอดรหัสแล้ว** ชั่วคราวใน `sessionStorage` ของแท็บนี้ (ไม่เก็บ password/key และไม่ใช้ localStorage/cookie) จึงกด Refresh หรือ Back กลับหน้ารวมแล้วไม่ต้องใส่รหัสซ้ำ ตรวจ fingerprint ของชุดเข้ารหัสและ SHA-256 ของเนื้อหาก่อนเรียกคืน หาก rebuild ชุดพอร์ตจะต้องปลดล็อกใหม่ ปุ่มล็อกพอร์ตล้าง cache และ iframe ทันที

แก้ปัญหา Back แล้วกรอบว่าง: ตอน `pagehide` ไม่ล้าง srcdoc เพื่อไม่สร้างการนำทางกรอบย่อยไปหน้าเปล่าระหว่างออกจากหน้า ดังนั้น BFCache อาจเก็บ DOM ที่ปลดล็อกไว้ด้วย เมื่อ `pageshow`/`popstate` ให้รอจังหวะคืนประวัติหน้าเสร็จ แล้วตรวจ cache และสร้าง iframe ใหม่ แม้แถบพอร์ตเดิมยังแสดงอยู่ ใช้ข้อความยืนยันจากหน้ารวมจริงก่อนแสดงสถานะโหลดเสร็จและเปิดใช้ลิงก์ หากไม่มีข้อความยืนยันใน 8 วินาที จะกลับหน้าล็อกอินพร้อมแจ้งข้อผิดพลาด ไม่ปล่อยกรอบว่างค้างไว้ การสร้างกรอบใหม่จะเริ่มหน้ารวมจากด้านบน ไม่ได้เก็บตำแหน่งเลื่อนเดิม รอบนี้แก้ตามภาพปัญหาและทดสอบจำลอง ไม่ได้ยืนยันในเบราว์เซอร์จริง

ปิดแท็บ/หน้าต่างตามปกติแล้ว session สิ้นสุด แต่ฟังก์ชัน restore session/reopen closed tab ของเบราว์เซอร์อาจกู้ session กลับมาได้ และแท็บที่เปิดจาก opener อาจได้สำเนา session เริ่มต้น จึงให้กดล็อกพอร์ตเมื่อต้องการล้างสถานะแน่นอน Cache นี้เป็น plaintext ชั่วคราว ไม่ใช่พื้นที่เก็บลับจากผู้ที่ควบคุมเบราว์เซอร์หรือสคริปต์ origin เดียวกัน การเปิดผ่าน `file://` หรือปิดสิทธิ์ storage อาจไม่รองรับ: ยังใส่รหัสเปิดดูได้ แต่แถบบนจะแจ้งว่าไม่สามารถจำแท็บและ Refresh ต้องใส่รหัสใหม่ ขนาด HTML จำกัด 5,242,880 หน่วยอักขระ JavaScript (ไม่ใช่จำนวน bytes) และหาก storage เต็มก็ใช้โหมดไม่จำแท็บแทน

ทดสอบ logic ด้วย `tools/verify-tab-session.mjs` และ `tools/verify-collection-update.mjs` ใน Node.js โดยไม่เปิด/รัน CAD ไม่ได้ยืนยันการทำงานใน browser จริงรอบนี้ แหล่งอ้างอิง lifecycle/ข้อจำกัด: [MDN sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)

ใช้ HTTPS เมื่อขึ้นเว็บ หรือ localhost ขณะตรวจในเครื่อง เนื่องจาก Web Crypto ต้องใช้ secure context การเปิด HTML จากไฟล์โดยตรงขึ้นกับเบราว์เซอร์ จึงยังไม่รับรองทุกเบราว์เซอร์ ไม่มี dependency จาก CDN/fonts ภายนอก และ CSP ปิด form submission/network connections ของตัวล็อกและพอร์ตภายใน

ตรวจในเครื่อง: เปิด PowerShell แล้วรัน `tools/start-preview.ps1` จากโฟลเดอร์นี้ จากนั้นเปิด http://127.0.0.1:8767/ ในเบราว์เซอร์ ปิดตัวอย่างด้วย Ctrl+C สคริปต์ให้บริการเฉพาะ `publish/` และรับการเชื่อมต่อเฉพาะเครื่องนี้ ไม่ใช่ระบบตรวจรหัสฝั่งเซิร์ฟเวอร์ ไม่เผยแพร่ private/source ใช้ Python ที่มีในเครื่องหรือ runtime ที่ติดตั้งมากับ Codex โดยไม่ดาวน์โหลดเพิ่ม

## ข้อจำกัดที่ต้องเข้าใจ

- เป็น encrypted static portfolio ไม่ใช่ระบบบัญชี/สิทธิ์ฝั่งเซิร์ฟเวอร์ ทุกคนดาวน์โหลด ciphertext ได้และสามารถลองเดารหัสแบบ offline จึงต้องใช้รหัสยาว ไม่ใช่รหัสสั้นหรือรหัสที่ใช้กับบัญชีอื่น
- คนที่มีรหัสและเปิดดูแล้วสามารถคัดลอก/บันทึกเนื้อหาได้ ไม่มี DRM และไม่สามารถถอนเนื้อหาที่ผู้ชมดาวน์โหลดแล้วได้
- ผู้ที่ควบคุมไฟล์เว็บ/hosting สามารถแก้ JavaScript ให้ขโมยรหัสได้ ต้องใช้ hosting ที่ไว้ใจได้และ HTTPS การไม่ส่งรหัสเป็นคุณสมบัติของชุดโค้ดนี้ ไม่ใช่ข้อรับรองสำหรับชุดที่ถูกดัดแปลง
- เปลี่ยนรหัสต้องเข้ารหัสใหม่; ผู้ชมที่เก็บ ciphertext เก่าและรหัสเก่าอาจยังเปิดสำเนาเก่าได้
- JavaScript strings/DOM/หน่วยความจำอาจถูกเก็บโดยเบราว์เซอร์/ส่วนขยาย จึงไม่อ้างว่าล้าง secret จาก memory ได้สมบูรณ์
- ไม่ใส่ source AutoLISP, audit report ที่มี path ในเครื่อง หรือไฟล์ดาวน์โหลด CAD ลงใน bundle รอบนี้ ผลงานยังมีสถานะรอทดสอบ CAD ตามหน้าแรกเดิม

หน้า Password ใช้แนวทางภาพจากไฟล์ที่ผู้ใช้ให้ `starfield_warp_login.html` โดยทำใหม่ให้มีเฉพาะช่อง Password และตัด white flash ออก มีปุ่มหยุด animation และเคารพ prefers-reduced-motion ไม่แก้ไฟล์อ้างอิงเดิม

แหล่งอ้างอิงทางเทคนิค: [MDN deriveKey](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey), [MDN AES-GCM parameters](https://developer.mozilla.org/en-US/docs/Web/API/AesGcmParams), [OWASP password storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
